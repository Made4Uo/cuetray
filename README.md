# CueTray

Snip a screenshot, write what you want done, and queue it as a numbered cue in your project.
When your AI coding assistant is free, it picks up the next cue with `/next-cue` (Claude Code,
Gemini CLI) or `$next-cue` (Codex), screenshots included. Windows only.

**Download:** the latest installer is under [Releases](https://github.com/Made4Uo/cuetray/releases/latest).

**Guide and pricing:** [cuetray.com](https://cuetray.com). Free for 14 days, then $14.99 once,
one license per device.
